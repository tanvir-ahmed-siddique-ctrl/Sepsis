# PredictRx Sentinel — top-band Congress evidence plan

Top-band scores are targets, not entitlements. Judges can only score evidence
that exists and is presented accurately. This plan separates repository work
from external proof that the founder must obtain from real people.

## 1. Innovation — target 16–20

### Defensible differentiator

Do not pitch “another sepsis LightGBM.” Pitch a systems-level invention:

> An evidence-gated ICU intelligence operating layer that validates hospital
> data, exposes measurement uncertainty, can abstain, keeps AI silent while
> local evidence is collected, and technically prevents live alerts until
> governance gates pass.

### Evidence already built

- one canonical pipeline for FHIR, HL7 ORU, HL7 ADT, NDJSON, CSV, native API,
  monitor relay and offline bedside charting;
- code/unit validation, quarantine, idempotency, late-data revision and audit;
- frozen Run 4, temporal features, calibration, TreeSHAP and TrustGate;
- Alert / Watch / Verify data / Abstain states;
- ward NEWS2 isolated from ICU ML;
- versioned evidence retrieval that refuses treatment and dosing requests;
- negative challenger ledger: neural, graph, residual and tabular alternatives
  were rejected when they failed the locked gate.

### To reach top band

- demonstrate one Verify-data or Abstain case, one missed detection and one
  false-alert case—not only a successful case;
- explain why disciplined rejection of complexity is AI engineering;
- obtain an independent AI/clinical-safety reviewer statement confirming that
  the architecture is meaningfully differentiated. This is external evidence,
  not a repository checkbox.

## 2. Technical execution — target 16–20

### Evidence already built

- working Next.js, FastAPI, PostgreSQL/SQLite, edge MLLP and Docker stack;
- 220 ML, backend, frontend and edge tests in the current tree;
- frozen model hash, migrations, backup/restore, audit-chain verification,
  health metrics and offline preflight;
- local/OIDC authentication, TOTP, scoped users and integration keys;
- generic ADT A01/A02/A03 plus mapping registry SHA-bound sign-off;
- offline chart outbox and deterministic restart behavior.

### Remaining production evidence

- signed repeatable installer/enrolment and rollback release;
- bed-master bulk import and identity correction/merge workflow;
- TLS/secret-manager deployment profile and independent penetration-test
  disposition;
- load, soak, recovery-time and recovery-point evidence;
- real vendor conformance test, not only synthetic messages;
- metadata-only fleet control plane after site requirements are known.

Code can move this category into the lower top band. A real site deployment and
independent security evidence are needed to defend the highest marks.

## 3. Business model and global readiness — target 16–20

### Evidence already built

- defined buyer, users, one-ICU wedge and offer ladder;
- paid readiness → integration → workflow/research subscription;
- on-prem hospital data plane and future metadata-only control plane;
- discovery pricing ranges, implementation cost tracking and stop rules;
- FHIR, HL7, LOINC, IEEE 11073 and Bangladesh Core FHIR direction.

### External evidence required

At least:

- 8–12 recorded problem interviews;
- two cross-functional hospital workshops;
- one LOI, dated paid-readiness discussion or written procurement interest;
- documented buyer, budget owner, procurement route and current alternative;
- one source inventory with no patient records;
- one tested quotation with explicit one-time and recurring components.

No wording change can substitute for market validation.

## 4. Real-world impact and ethical AI — target 16–20

### Defensible Bangladesh relevance

- DGHS's 25 January 2024 public-hospital table lists 778 ICU beds across the
  facilities in that report.
- 2025 reporting citing DGHS data states 1,372 ICU beds across 74 public
  hospitals, with 55% in Dhaka; use as secondary reporting, not a live registry.
- Bangladesh studies have reported serious sepsis burden, including a small
  2009 prospective cohort across 14 ICUs with 49.2% hospital mortality and a
  2014–15 Rajshahi cohort with 46.9% mortality. These historical cohorts show
  relevance; they do not estimate current national mortality.

### Measures for the first deployment

- feed coverage, provenance, lag, quarantine and downtime;
- handoff completeness/time and user burden;
- training completion, adoption and support load;
- local prevalence, calibration, discrimination, alert-burden simulation and
  subgroup uncertainty;
- backup restore, access review and security incidents;
- implementation cost and continuation decision.

### External evidence required

Documented high social return requires measured local results and accountable
hospital review. Do not convert historical mortality figures into “lives
saved” or revenue claims.

## 5. Scalability and NRB/global collaboration — target 8–10

### Evidence already built

- modular connectors and canonical semantics;
- CPU inference and offline-capable hospital-local deployment;
- repeatable governance and mapping runbooks;
- identifiable data remains local by default;
- architecture supports reusable vendor packs across countries.

### External evidence required

Recruit one named NRB/global collaborator with a bounded contribution:

- FHIR/HL7 architecture review;
- biostatistical protocol review;
- clinical-safety/human-factors review;
- security threat-model review;
- international-market comparison.

Record affiliation, contribution, conflicts, date and permission to name them.
A logo or informal message is not collaboration evidence.

## 6. Presentation — founder-owned target 8–10

Repository support now includes:

- kiosk-style three-minute judge page and timer;
- typical, missed, false-alert and stable evidence cases;
- Dataset A replay / Dataset B metric distinction;
- model reasoning page, readiness passport and recovery runbook;
- one-page judge brief and offline preflight.

Founder must provide:

- rehearsed delivery;
- slide/PDF and recorded-video fallback;
- five independent timed reviews;
- exact answers for transfer risk, low precision, no Bangladesh validation,
  regulatory status, buyer and why the core model is deliberately simple.

## Score ceiling today

A defensible current midpoint remains around 67/100. Repository work can
improve technical and presentation evidence, but top-band business, impact and
NRB scores require real external proof. With one credible hospital commitment,
one accountable adviser/NRB contribution and polished evidence, approximately
72–78 is more defensible. Higher scores depend on judge judgment and real
deployment evidence, not feature count.
